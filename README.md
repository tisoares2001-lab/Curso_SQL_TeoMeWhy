# 🗄️ SQL Mastery Roadmap

Um curso com os requisitos essenciais para dominar SQL, estruturado para construir raciocínio lógico em problemas reais de negócios e pavimentar o caminho para oportunidades internacionais em análise de dados.

## 📌 1. Fundamentos e Modelagem
- [ ] **Básico Essencial:** Domínio total das instruções `SELECT`, `WHERE`, `ORDER BY`, `LIMIT` e operadores lógicos (`AND`, `OR`, `IN`, `LIKE`).
- [ ] **Conceito Relacional:** Entendimento claro da comunicação entre tabelas através de Chaves Primárias (PK) e Chaves Estrangeiras (FK).

## 🔄 2. Manipulação e Agregação de Dados
- [ ] **Joins (Cruzamentos):** Diferença prática e aplicação de `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN` e `FULL JOIN`.
- [ ] **Agrupamentos:** Uso avançado de `GROUP BY` e `HAVING` junto com funções de agregação (`SUM`, `AVG`, `COUNT`).
- [ ] **DML e DDL:** Capacidade de criar, alterar e deletar estruturas (`CREATE`, `ALTER`, `DROP`) e manipular dados (`INSERT`, `UPDATE`, `DELETE`).

## 🚀 3. Tópicos Avançados
- [ ] **Subqueries e CTEs:** Uso da cláusula `WITH` (Common Table Expressions) para organizar consultas complexas em blocos lógicos.
- [ ] **Window Functions:** Domínio de funções analíticas avançadas como `ROW_NUMBER()`, `RANK()`, `LEAD()` e `LAG()`.
- [ ] **Tratamento de Dados:** Funções nativas para extrair, limpar e padronizar textos (`SUBSTRING`, `REPLACE`) e manipular datas.

## 🧠 4. Prática e Retenção
- [ ] **Otimização:** Entendimento sobre o uso de índices para garantir a performance do banco de dados.
- [ ] **Projetos Aplicados:** Resolução de desafios reais com bases de dados cruas para compor repositórios de portfólio.
- [ ] **Fixação Contínua:** Estruturação de comandos e sintaxe em formatos curtos (separados por ponto e vírgula) para exportação e revisão.
